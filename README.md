# 🧪 LabChem — شبیه‌ساز آزمایشگاه شیمی

**LabChem** یک برنامه آزمایشگاهی تعاملی است که به شما امکان می‌دهد با بیش از **۸۹ ماده شیمیایی** (فلزات، نافلزات، گازهای نجیب و...) کار کنید، واکنش‌های شیمیایی را شبیه‌سازی کنید و ساختار مولکول‌ها را با تصاویر واقعی و مدل‌های سه‌بعدی مشاهده کنید.

---

## ✨ ویژگی‌ها

- 🧫 **پشتیبانی از ۸۹+ ماده شیمیایی**: شامل فلزات، نافلزات، گازهای نجیب، اسیدها، بازها و ترکیبات رایج.
- ⚗️ **شبیه‌سازی واکنش‌های شیمیایی**: پشتیبانی از طیف گسترده‌ای از واکنش‌ها با نمایش معادله و نتیجه.
- 🖼️ **تصاویر واقعی مولکول‌ها**: مشاهده تصاویر واقعی و ساختار مولکولی مواد.
- 🔬 **مدل بور (Bohr Model)**: نمایش آرایش الکترونی اتم‌ها به سبک مدل بور.
- 🧱 **شبکه مولکولی**: نمایش شبکه و آرایش مولکول‌ها در مواد مختلف.
- 📐 **نمونه مدل (Sample Model)**: مشاهده نمونه‌های سه‌بعدی و مدل‌سازی ساختار مواد.
